## 1. 原则：模拟实际使用

一篇新文献进入地图之前，它的任何值都不能出现在：

- 偏移文献对的判定中；
- σ<sub>doc</sub> 中；
- 被预测条目的其余证据单元中。

各设计中所有可能的泄漏途径，以及本计划如何堵住：

| 设计 | 途径 | 处理 |
|---|---|---|
| 条目分折、近重复合并 | 留出单元 H 的文献，它们对其他化合物的值在训练条目中，可以构成被标记的 pair | 判断「被触及」时，忽略任何包含 H 中文献的 pair |
| 条目分折、近重复合并 | H 的文献的其他值进入 σ<sub>doc</sub> | 这是事先声明的条目分折设计固有的性质，不改动，在稿件中写明；文献分折没有这个问题 |
| 文献分折 | 现在的代码只按条目过滤 pair，含留出文献的 pair 仍然保留 | 只用两篇文献都不在留出折中的 pair |
| 文献分折 | 合并单元按字母序最前的文献分折；含留出文献的合并单元，留在训练中，也留在其余单元中 | **严格版**：任何含有留出折文献的单元，都从训练中与其余单元中删去；G 的预测重新计算 |
| 时间切分 | 只用截止年份及以前的文献 | 不变，本来就没有泄漏 |
| E11 新靶点 | 同条目分折 | 同条目分折；另按文献定义「新」，见 Q1 |

偏移文献对的定义不变：至少 3 个共享条目，中位差的绝对值 ≥ 1，至少 80% 的差与中位数同号。差由逐文献的值计算（`document_values`，`merge_identical=False`），只用该设计在该折中允许的条目与文献。

## 3. 问题、量与判定（全部事先写定）

### Q1：无泄漏时，规则 P 是否提高 supported 格子对新文献的一致率？

- **设计：**5 种，即条目分折、严格文献分折、近重复合并、时间切分（2015 年）与 E11。每种设计，两个端点分开。
- **量：**
  - supported 一致率：不用规则，与用无泄漏的规则；
  - 被降级的比例，以及被降级格子的一致率；
  - 每个数据集的上升量：用规则后 supported 的一致率，减去不用规则时的。
- **检验：**
  - 在至少有 1 个被降级预测的数据集上，做双侧 Wilcoxon（`zero_method="wilcox"`；n ≤ 25 且没有并列时用精确值，否则用正态近似，并写明用的是哪一种）；
  - 10 个检验（5 种设计 × 2 个端点）为一个 Holm 族。
- **补充：**
  - 都去掉 CHEMBL5113 与 CHEMBL4792 之后，重复上面的分析；
  - E11 另做一版：忽略在 52 个评价数据集的全部数据中已被标记的 pair，即只用新的 pair。另外报告新旧数据集之间共用文献的数目。
- **判定：**规则 P「提高了 supported 格子对新文献的可靠性」，须在同一个端点上同时满足：
  1. 严格文献分折中，上升为正，且 Holm P < 0.05；
  2. 时间切分中，上升的点估计 ≥ 0。时间切分中有降级预测的数据集很少，检验的效力低，所以这里只要求方向；
  3. 任何设计中都没有显著的下降（Holm P < 0.05）。
  - 否则判为「未被证实」。

### Q2：被触及的 supported 格子，是否构成一个介于中间的可靠性等级（三态显示）？

- **三组：**
  - St：supported 且被无泄漏的 flag 触及；
  - Su：supported 且未被触及；
  - U：uncertain，即支持度 < 0.8，不论是否被触及。
- **量：**
  - 三组各自的一致率，带两阶段 95% CI；
  - St 的平均支持度，与平均预测概率；
  - 每个数据集的差 d = 一致率(St) − 一致率(Su)，只用至少有 5 个 St 预测的数据集。
- **检验：**d 做双侧 Wilcoxon；5 种设计 × 2 个端点为一个 Holm 族。
- **判定：**「三态显示有依据」，须在同一个端点上同时满足：
  1. 在条目分折或严格文献分折中，d < 0，且 Holm P < 0.05；
  2. 时间切分中 d 的点估计 ≤ 0；
  3. 在第 1 条的那种设计中，St 的合并一致率高于 U，且两者之差的两阶段 95% CI 不含 0。
  - 否则判为「没有依据」。

### Q3：偏移文献对是否揭示了可以辨认的数据错误？（描述性分析，用全部数据，不分折）

- **对象：**对 52 个评价数据集、23 个新数据集，以及三个详细靶点，用软件默认的方法（`chemgridmap.evidence.document_pair_offsets`），在每个数据集的全部数据上找出被标记的 pair。
- **特征：**每一对按以下顺序判定，取第一个符合的。
  - **S1，靶点互换：**存在另一个已下载的同端点靶点 T2，在两篇文献于两个靶点都有值的化合物上（至少 3 个），至少 80% 的化合物同时满足：
    - |A 在 T1 的值 − B 在 T2 的值| ≤ 0.05；
    - |B 在 T1 的值 − A 在 T2 的值| ≤ 0.05。
    - 值取 `standard_relation` 为「=」的原始 pChEMBL，按文献 × 母体取中位数。可供比对的，只有 86 + 60 个已下载的文件，所以这是下限。
  - **S2，单位换算：**中位差的绝对值与 3、6 或 9 相差不超过 0.1，且至少 80% 的差落在中位差 ± 0.2 之内。
  - **S3，恒定平移：**差的四分位距 ≤ 0.1，中位差的绝对值 ≥ 1，且不属于 S2。
  - **S4，测定类型不同：**两篇文献在共享条目上的记录，多数 `assay_type` 不同。
  - **S5，ChEMBL 已有标记：**共享条目的原始记录中，有 `potential_duplicate = 1`，或 `data_validity_comment` 非空。
  - **S6，来源不同：**两篇文献的 `src_id` 不同，例如专利与期刊。
  - **S0：**以上都不符合。
- **量：**
  - 被标记的 pair 数，以及触及的条目数；
  - 各特征所占的比例，按 pair 与按触及的条目分别计算，带精确二项 95% CI；
  - 列出触及条目最多的 15 对，写明数据集、文献、共享条目数、中位差、特征与证据（例如 S1 中对调的化合物数）。
  - **对照：**在同一些数据集中，至少有 3 个共享条目、但未被标记的 pair，同样计算 S1 的比例，用来估计互换中有多少因为偏移太小而没有被标记。
- **判定：**「偏移文献对揭示了可辨认的数据错误」：
  - **强：**S1–S3 的 pair，至少占被标记 pair 的 25%，或占被触及条目的 25%；
  - **弱：**S1–S3 至少有 3 对，分布在至少 2 个数据集中（同一对文献出现在两个靶点上，只算一次），但达不到强的标准；
  - **无：**S1–S3 少于 3 对。

- **判定：**不设判定。这一节是为正文与表 3 提供数字。

## 4. 结论如何写进稿件（事先写定）

| Q1 | Q2 | Q3 | 规则 P 在稿件中的定位 |
|---|---|---|---|
| 被证实 | — | — | 规则 P 是经过验证的显示规则，可以作为创新点 |
| 未被证实 | 有依据 | 强或弱 | 改为三态显示（被触及的 supported 单独显示），并作为揭示数据错误的审计工具。可以作为创新点，表述限于证据所及 |
| 未被证实 | 有依据 | 无 | 三态显示，作为描述性的显示约定；不作为主要创新点 |
| 未被证实 | 没有依据 | 强 | 偏移文献对作为数据审计工具；降级不再作为默认 |
| 未被证实 | 没有依据 | 弱或无 | 规则 P 只作为透明的可选显示，不声称任何益处；摘要、科学贡献与结论中删去它的增益 |

- **任何情况下：**
  - 摘要中「82% → 87%、90% → 93%」以及「过度自信主要来自偏移文献对」，都换成无泄漏的结果；
  - E11 照实报告：按计划，原分析达到了标准；无泄漏之后的结果；以及食欲素受体的数据错误。
- **软件的默认行为：**由用户根据结果决定，这里不预先确定。
