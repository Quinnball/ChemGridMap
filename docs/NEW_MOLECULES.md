# 新分子：参照图建立后的插入与证据审计

先选择参照数据，例如某个靶标的 ChEMBL 活性导出，生成地图，再从地图页点击
“加入新分子”。新分子可以是 AI 生成的候选，也可以是自己测定的化合物。
本功能用于证据审计与探索，不预测活性。

## 输入与会话

- 仅按 Morgan 指纹排布的参照图支持插入；用户坐标、嵌入向量和其他表示不支持。
- 上传 CSV/TSV，必选 SMILES 列；ID、活性、关系符、证据单元和标签列可选。
  未选 ID 时按输入顺序生成 `N00001`、`N00002` 等编号。
- 活性列为空时作为 AI 生成或未测的新分子；选活性列时可指定固定单位或单位列。
  标签仅用于显示和筛选，不影响计算。
- 建议几十到几百个分子，检查后最多 1,000 个；超限或空格不足时报错。
- 同时显示一组新分子；再次插入替换显示中的一组，“移除新分子”清除当前一组。
  页面刷新保留，改变设置重建参照图后重新插入，换参照数据则清除。
  会话保留指当前应用进程，不表示关闭服务器后自动恢复。

## 结构与测定记录

结构检查沿用参照数据的处理策略，保留立体化学。无效 SMILES 不插入；文件内
相同结构保留首次出现的分子；与参照分子结构相同的分子不新增格子，其 ID 可
用于打开对应参照分子的检查器。重复结构的 ID 解析到第一次出现的分子。

自己的测定记录按 ID 归到化合物；浓度换算为 `pActivity = -log10(摩尔浓度)`。
支持 M、mM、uM（含 µM、μM）、nM、pM，或已换算的 pActivity。关系符不为
`=`、无效或非正浓度、未知单位等记录排除并记录原因。按化合物计算中位数、
范围、记录数和证据单元数，用参照图阈值划分类别。记录跨度超过参照图阈值时
标记跨度大，不改变类别。结构检查在化合物层面进行。

与参照结构相同的实测化合物显示自己的中位数、参照中位数和差值（自己减参照）。
审计汇总差值的中位数和范围，可用于检查测定体系是否与文献一致。
选择证据单元列后，按原有规则检查成对偏移：至少 3 个共有条目，绝对中位差
至少 1 个对数单位，同号比例至少 0.8；审计同时保留未触发阈值的已评估对。

## 固定参照图中的放置

1. 使用参照图的 Morgan 半径和位数计算 Tanimoto 相似度。
2. 选最高分的参照分子作为目标，并列时选字典序最小的 ID，与近邻表排序一致。
3. 新分子按最高 Tanimoto 降序、ID 升序依次放置。
4. 仅搜索原网格行列范围内未被参照或先前新分子占用的格子。
5. 选择距目标参照格子欧氏距离最近的空格；并列时先行号、后列号。

输出目标参照 ID、相似度和以格为单位的放置距离。所有参照格子保持不变，插入
不重新计算参照投影、分组、可靠性或导出文件。二维投影图不绘制新分子。
结构组沿用既有组中心；新分子分配不改变参照组成员或组核心。

## 近邻证据

取最相似的 5 个参照分子，第五名并列全部保留。只有 Tanimoto 不低于
`group_similarity`（默认 0.6）的近邻参与汇总；关闭分组时仍使用此阈值。

| 值 | 显示名称 | 规则 |
|---|---|---|
| `none` | 无相近的参照分子 | 没有达到阈值的近邻 |
| `insufficient` | 近邻证据不足 | 有相近近邻，但没有 `supported` 类别 |
| `active` | 近邻一致：活性 | 可靠近邻全部为活性 |
| `medium` | 近邻一致：中等活性 | 可靠近邻全部为中等活性 |
| `inactive` | 近邻一致：非活性 | 可靠近邻全部为非活性 |
| `mixed` | 近邻不一致 | 可靠近邻出现两个或更多类别 |

参照图未评估类别支持度时改用实测类别，检查器与审计明确提示这一限制。
自己的测定类别只与一致的近邻类别比较，显示一致或不一致及双方类别；其他
情况不比较。“这是相近参照分子的证据汇总，不是对该分子活性的预测。”

## 显示与导出

实测活性图层：未测新分子白底灰框，实测新分子按自己的类别填色并加
`#173e34` 深色框。类别支持度与近邻可靠性图层中新分子使用中性色，不参与
该图层计算。近邻证据图层中参照分子保留类别颜色，不透明度降至 0.25；
新分子填充表示自己的测定，外框表示近邻证据。

| 近邻证据 | 外框颜色 | 样式 |
|---|---|---|
| 活性 | `#2a9d8f` | 实线 |
| 中等活性 | `#e6a23c` | 实线 |
| 非活性 | `#c44e52` | 实线 |
| 不一致 | `#7a5195` | 虚线 |
| 证据不足 | `#8a99a6` | 点线 |
| 无相近参照 | `#b8c2cc` | 1.5 像素细实线 |

其余近邻证据框至少 3 屏幕像素；普通新分子框至少 1.5 屏幕像素，缩放时宽度
保持。新分子列表可按列排序、按类别和标签筛选、点击定位，下载当前显示行。
参照结构匹配、重复、无效等检查结果也保留在列表中。

每次插入保存到当次参照运行目录的 `new_molecules/<输入文件去掉扩展名>/`。
同名目录顺次加 `-2`、`-3` 等后缀，不覆盖或删除已有产物。

| 文件 | 内容 |
|---|---|
| `new_molecules_input.csv` | 原始上传字节，TSV 也不改写 |
| `new_molecules_check.csv` | `QUERY_CHECK_COLUMNS` 定义的逐分子结构检查 |
| `new_molecules.csv` | 每个新分子一行，含状态、标签、放置、分组、近邻证据和测定汇总 |
| `new_molecules_excluded_records.csv` | 仅自己的测定输入：全部被排除记录的原始列，加排除原因；没有排除时保留表头 |
| `new_molecules_neighbors.csv` | `QUERY_NEIGHBOR_COLUMNS` 定义的最相似近邻表 |
| `map_with_new_molecules.svg` | 实测活性参照图叠加新分子，仅 SVG |
| `new_molecules_manifest.json` | 输入 SHA-256、参照运行目录与 manifest SHA-256、参数、源码哈希和计时 |
| `new_molecules_results.zip` | 以上文件；未测输入六个，自己的测定输入七个 |

导出对话框同时提供参照文件和当前新分子文件。参照图原文件保持逐字节不变；
替换或移除只改变会话显示，不删除任何历史输出。

## 库与 CLI

`insert_new_molecules` 是浏览器与 CLI 共用的插入函数。
`build_grid_map(..., query_data=...)` 先建立完整参照图，再插入未测分子；
返回结果中的参照表、指标和原输出仍属于参照图，新分子结果单独保存。

CLI 参数保持不变：`--query-file`、`--query-smiles-column`、
`--query-id-column`。CLI 查询文件一律按未测分子处理；自己的测定新分子由
浏览器的活性列入口支持。通用活性记录作为主输入建图的原有功能继续保留。

模拟验收数据标注为 **SIMULATED – not real measurements**，不得当作真实测定。
